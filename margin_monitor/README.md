# 台股風險河流圖 V3.2｜每日全市場融資

這版回到 V3 的三條河架構：

1. 上市風險（週）
2. 上櫃風險（週）
3. 全市場融資壓力（日）

## 這版改了什麼

- 不再把上市融資、上櫃融資畫成兩條線。
- 每天分別取得 TWSE 與 TPEx 的**融資金額餘額**，再合併成一個台股整體融資餘額。
- 兩邊官方單位都是「仟元」，合併後前台轉成「億元」顯示。
- 只有同一天上市與上櫃融資資料都成功取得才納入總額，避免單邊資料失敗被誤判為融資暴減。

## 全市場融資壓力算法

保留 V3 的三個概念，但改為每日資料：

- 約 26 週餘額位階：130 個交易日滾動高低區間（50 分）
- 約 4 週融資增幅：20 個交易日變化率（35 分）
- 價跌資增背離：最多 15 分

「價跌資增背離」的價格端不只看加權指數，而是：

- 算 TAIEX 20 日報酬
- 算 TPEx 20 日報酬
- 依當日上市／上櫃融資金額占比加權
- 只有在「全市場價格下跌 + 全市場融資增加」同時成立時才加分

## 資料來源

- 臺灣證券交易所（TWSE）
  - 加權指數
  - 信用交易統計中的融資金額餘額
- 證券櫃檯買賣中心（TPEx）
  - 櫃買指數
  - 上櫃股票融資融券餘額表中的融資金額餘額

## 零付費原則

- 只使用 TWSE／TPEx 免費公開資料
- 不使用付費 API、資料庫或主機
- 部署維持 GitHub + Streamlit Community Cloud

## 部署

把 ZIP 解壓縮後，將檔案全部上傳覆蓋 GitHub 專案，再到 Streamlit Community Cloud **Reboot app**。

## 本機執行

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## 注意

每日融資需要逐交易日向兩個官方來源讀取資料，因此冷啟動會比純週資料慢。Streamlit 會快取 6 小時。
