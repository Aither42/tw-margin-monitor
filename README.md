# 台股決策助手 V4

V4 最大修改：三區價位不再只是技術線型，而是同時考慮：

- 技術結構
- P/E / P/B 等估值
- 月營收成長率
- 成長加速度
- 是否進入新營收平台
- ATR 波動

## 三區邏輯

### 較安全分批區
技術支撐與均線形成基礎錨點，再依估值與成長修正。
估值越貴，安全區會往下移；高成長只能部分抵銷高估值。

### 中性觀察區
股價尚未極端追價，但安全邊際不足，需等待基本面與籌碼確認。

### 高風險追價區
價格偏離技術錨點、接近近期壓力，且估值與成長不足以支持更高風險承擔。

## V4.3 調整

主畫面改為直接顯示三個「可操作的價格區間」：

- 🟢 低風險承接區：可分批建立或加碼
- 🟡 中風險觀察區：持有可觀察，新資金等回檔
- 🔴 高風險追價區：不追價

同時直接判斷「目前股價正落在哪一區」，並給出對應行動。

模型分數已退到進階展開區，不再作為主畫面核心。

若股價跌破低風險承接區下緣，系統不會把它當成「更安全」；會改為提醒先檢查基本面與趨勢是否破壞。

## V4.10 均線架構統一

技術分析均線現在只使用：

- **MA13**：短線趨勢與節奏
- **MA40**：中短期趨勢
- **MA63**：波段趨勢
- **MA150**：中長期結構
- **MA1000**：超長期趨勢代理，時間跨度約等於 200 週

注意：MA1000 是最近 1000 個「日收盤價」的平均，和真正以「週收盤價」計算的 200 週均線不會完全相同，但時間尺度接近。

為了讓 MA1000 能正常計算，Yahoo Finance 股價歷史預設抓取範圍已由 3 年擴充為 **5 年**。若個股上市交易日數不足 1000 日，MA1000 會自然顯示為無資料，不會硬補數值。

價格風險區的主要技術錨點仍使用 MA40 / MA63 / MA150 加上 40 / 63 日支撐；MA13 與 MA1000 分別負責短線與超長期趨勢判讀，避免 MA1000 距離現價太遠時扭曲承接區。


## V4.11 每日低風險掃描分頁

新增真正的 Streamlit 第二分頁：

- **🐾 軋軋個股分析**：原本的單一個股決策助手。
- **📋 每日低風險清單**：每日掃描股票池，找出進入低風險承接區的股票。

### 兩階段掃描

為避免一次對全市場逐檔呼叫 FinMind / Yahoo 基本面：

1. **第一階段技術初篩**
   - Yahoo Finance 批次下載 1 年行情。
   - 使用 MA40 / MA63 / MA150、ATR、40/63 日支撐做寬鬆候選篩選。
   - 這一步只是候選，不代表已進入低風險區。

2. **第二階段完整確認**
   - 對排名靠前的候選抓 5 年行情。
   - 完整計算 MA13 / MA40 / MA63 / MA150 / MA1000。
   - 抓 Yahoo Finance 基本面與 FinMind 月營收。
   - 使用與 V4.10 個股頁一致的估值 / 成長 / 技術價格區模型。
   - 只有最後落在「較安全分批區」者才出現在低風險清單。

### 今日新進

掃描紀錄保存在：

`data/low_risk_scan_history.csv`

判定方式：

- **🆕 今日新進**：前一個已保存交易日不是低風險區，今天完整確認進入。
- **🟢 持續低風險**：前一個已保存交易日已在低風險區。
- **✨ 首次確認**：沒有更早的完整確認紀錄，因此不能假裝是「今日新進」。

週末或同一交易日重跑會覆蓋同一行情日紀錄，不會因為日曆日期變化就製造假訊號。

### 掃描規模

第二分頁提供 100 / 300 / 600 / 全部等模式。

- 100、300、600 是測試 / 加速模式；為避免只掃低代號股票，會從股票池均勻抽樣。
- 「全部」才是全市場模式，但 Yahoo Finance 批次下載可能花數分鐘。
- 第二階段完整確認數可調 10～60 檔。
