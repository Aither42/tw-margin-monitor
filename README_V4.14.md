# 軋軋 V4.14 整合版

本版以軋軋 V4.12 為底稿，保留每日低風險清單及 AI Overheat Monitor，正式加入你提供的台股風險河流圖 V3.2，並將融資模組升為 V3.3 每日補抓版。

## 這次修正

- 軋軋首頁下方加入真正的台股融資風險河流圖，也可從主畫面入口直接開啟專頁。
- 上市風險、上櫃風險、全市場融資壓力全部使用每日交易資料，不再把指數縮成週資料。
- 指數風險以 100 日均線、60 日動能、20 日年化波動率對應原 20／12／4 週尺度。這是每日模型，分數不會與原週模型完全相同。
- 全市場融資仍以同日上市＋上櫃融資金額相加，沿用 130 日餘額位階、20 日增幅及價跌資增背離。
- 保存成功的融資與指數資料，更新時只補抓缺日並刷新最近五個交易日；中斷後再按更新可接續。
- 降低同時請求數、限制請求速度、加入第二輪缺日重試。上櫃優先用官方 JSON，失敗再嘗試原官方 HTML。
- 遇到官方 403／428／429 限制存取，暫停該來源至少三分鐘，遵守較長 Retry-After，本輪不反覆重送；稍後再按更新接續補抓。
- 驗證官方回傳日期及正數金額，拒絕把其他日期的回應存成當日資料。
- 以兩市場已取得的指數日期聯集核對缺日，避免一邊指數漏抓就把那天整個忽略。
- 缺日列出日期和原因；不補零、不以前日融資冒充、圖線保留斷點。20 日計算依交易日對齊，避免刪掉缺日後把 20 筆資料誤當 20 個交易日。
- 個股 K 線風險帶與這張全市場融資圖為兩個不同功能，兩者均保留。

## 使用

開啟首頁下方「台股風險河流圖 V3.3」，按「載入／更新並補抓缺日」。第一次建立歷史可能需要數分鐘，進度會顯示，成功資料即時保存。之後更新通常只需補缺日與最近資料。

「顯示最近幾週」只決定畫面長度，每個交易日仍是一筆。改變範圍後再按更新。

融資官方資料可能晚間才公布；當日尚未公布會留待下一次更新。此版由使用者按鈕觸發，未額外安裝背景每日排程。

## 資料保存

- 融資歷史：`data/margin_monitor/history.sqlite3`
- 每日個股清單：`data/low_risk_scan_history.csv`
- AI 歷史：`data/ai_overheat/history.csv`

本機更新請保留 data。Streamlit 免費雲端重建若清除執行磁碟，需重新建立歷史；本版未使用外部付費儲存服務。

若兩市場同時無法取得某月份指數，就無法僅憑本地指數推知該月所有交易日。畫面會列出月份失敗警告；「已知交易日」完整度不代表已驗證官方全年交易日曆。

官方可能修訂歷史值，本版會重新核對指數月份、刷新最近五日融資；更早已成功保存的融資不每次全量重抓。

## 驗證

執行 `python -m unittest discover -s tests -p test_margin_monitor.py`。

測試涵蓋暫時失敗後重試、成功資料重開仍存在、只補缺日及最近五日、刷新失敗不清除舊值、錯誤日期拒收、JSON/HTML 備援、兩市場金額合併與缺日計算。另以 Streamlit AppTest 驗證四個頁面、首頁融資圖、更新及頁面切換。

即時測試紀錄見 `驗證紀錄.md`。外部服務未來仍可能暫時限流或延遲，本版會保留資料並顯示缺日。
